    jacobian_const_p() ¶

    Computes numerical Jacobian at constant pressure. Returns a N_s+1 x N_s+1 array [jac].

    jacobian_const_v() ¶

    Computes numerical Jacobian at constant density. Returns a N_s+1 x N_s+1 array [jac].

    jac_contribution() ¶

    Computes contributions of each reaction to numerical Jacobian. Given that g = Sr = Sum_k S_k r^k, it follows that J(g) = Sum_k^(2nr) J_k, where J_k = Jac(S_k r^k) S_k r^k is the product of the k-th column of the matrix S and the k-th component of the vector r. Returns a (2*Nr, nv, nv) array [jacK], whose sum over the first axis equals the (full or kinetic) Jacobian.

    jacobian_diagonal_const_p() ¶

    Computes (an approx. to) the diagonal of the numerical Jacobian at constant pressure. Returns a N_s+1 array [diagjac].

    jacobian_diagonal_const_v() ¶

    Computes (an approx. to) the diagonal of the numerical Jacobian at constant density. Returns a N_s+1 array [diagjac].

    jacThermal() ¶

    Correction that constrains the species Jacobian to the manifold of constant enthalpy (const_p) or constant internal energy (const_v): J_constrained = J_YY - jacThermal, with jacThermal[i,j] = dg_i/dT * e_j/c, where e_j = h_j, c = cp (const_p) or e_j = u_j, c = cv (const_v), mass-specific species properties.

    calc_exhausted_modes(**kwargs) ¶

    Computes number of exhausted modes (M). Optional arguments are rtol and atol for the calculation of M. If not provided, uses default or previously set values

    calc_subspaces(**kwargs) ¶

    Computes subspaces partitioning (M and H). Optional arguments are rtol and atol for the calculation of M, and rtol and atol for the calculation of H. If not provided, uses default or previously set values

    calc_TSR(**kwargs) ¶

    Computes number of exhausted modes (M) and the TSR. Optional arguments are rtol and atol for the calculation of M. If not provided, uses default or previously set values. The calculated value of M can be retrieved by passing the optional argument getM=True

    calc_TSRindices(**kwargs) ¶

    Computes number of exhausted modes (M), the TSR and its indices. Optional argument is type, which can be timescale or amplitude. Default value is amplitude. Other optional arguments are rtol and atol for the calculation of M. If not provided, uses default or previously set values. The TSR value can be retrieved by passing getTSR=True, in which case the method returns (TSR, indices). Optional norm_cut (scalar or nv-long array, default None): with index_norm='abs', modes whose CSP indices have a sum of absolute contributions smaller than norm_cut get zero indices (units of that sum: 1/s for type='timescale', the mode-amplitude units for type='amplitude').

    calc_CSPindices(**kwargs) ¶

    Computes number of exhausted modes (M) and the CSP Indices. Boolean keywords select the indices to compute (all default False): API (amplitude participation), TPI (timescale participation), Impo (fast/slow importance), species_type (fast/slow/trace species). Returns [API, TPI, Ifast, Islow, species_type] (None for those not requested), plus M if getM=True. Optional arguments are rtol and atol for the calculation of M. If not provided, uses default or previously set values. Optional norm_cut (scalar or nv-long array, default None): with index_norm='abs', rows (modes for API/TPI, variables for Ifast/Islow) whose sum of absolute contributions is smaller than norm_cut are set to zero instead of being normalized (units of that sum: the rate of the mode amplitude or variable, 1/s for TPI).

    calc_extended_TSR(**kwargs) ¶

    Computes number of Extended exhausted modes (Mext) and the extended TSR. Caller must provide either a diffusion rhs with the keyword diff or a convection rhs with the keyword conv, or both (nv-long arrays). Optional arguments are rtol and atol for the calculation of Mext. If not provided, uses default or previously set values. The calculated value of Mext can be retrieved by passing the optional argument getMext=True

    calc_extended_TSRindices(**kwargs) ¶

    Computes number of Extended exhausted modes (Mext), the extended TSR and its indices. Caller must provide either a diffusion rhs with the keyword diff or a convection rhs with the keyword conv, or both (nv-long arrays). Other optional arguments are rtol and atol for the calculation of Mext. If not provided, uses default or previously set values. The extended TSR can be retrieved by passing the optional argument getTSRext=True, in which case the method returns (TSR_ext, indices). Indices refer to the 2Nr reactions, then the nv convection and the nv diffusion terms.

    kernel() ¶

    Computes CSP kernel. Its dimension is Nspecies + 1. Returns [evals,Revec,Levec,amplitudes].

    kernel_kinetic_only() ¶

    kernel_constrained_jac() ¶

    Computes constrained kernel (constant enthalpy for const_p, constant internal energy for const_v). Its dimension is Nspecies. Returns [evals,Revec,Levec,amplitudes].

    detectFrozenModes(M, stateYT, Revec, Levec, Smat, rvec, rtol, atol) ¶

    Identifies frozen modes among the M exhausted modes (or all modes, if needed). A mode is frozen if the sum of absolute projected reaction rates is small.

    Parameters:

    M : int Number of exhausted modes (returned by findM). stateYT : array State vector [Species... , T]. Revec : array Right eigenvectors (rows). Levec : array Left eigenvectors (rows). Smat : array Stoichiometric matrix. rvec : array Reaction rates vector. rtol : float Relative tolerance. atol : float Absolute tolerance.

    Returns:

    frozen_indices : list Indices of modes that are frozen.

    Returns eigensystem (evals, Revec, Levec). Input must be a 2D array. Both Revec (since it is transposed) and Levec (naturally) contain row vectors, such that an eigenvector can be retrieved using R/Levec[index,:]

    CSP pointers following Lam & Goussis. - pointers[m,k] = diag_k(Q_m) - Q_m = A_m B_m - m is the mode index - k is the species index
